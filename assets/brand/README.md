# Brand Assets

This is the repository-wide source directory for product artwork. Keep editable SVG, PNG, and source artwork here rather than copying files into individual clients.

`npm run brand:sync` copies `logo.svg` into the VS Code extension's packaged `media/` directory. The TypeScript brand configuration is `packages/branding/src/index.ts`.
