*truss.txt*                    Truss coding agents for Neovim

==============================================================================
INTRODUCTION                                                     *truss.nvim*

truss.nvim is a keyboard-first client for the provider-neutral Truss runtime.
The plugin renders the interface in Lua while model access, tools, approvals,
credentials, and workspace policy stay in the local truss-cli service.

Requirements:

- Neovim 0.10 or newer
- Node.js 20 or newer
- truss-cli 0.1.14 or newer, installed and configured

After installation, run:

  :checkhealth truss

This checks local versions and dependencies without contacting a provider.
Use :TrussTestConnection separately to test the configured provider.

==============================================================================
SETUP                                                          *truss-setup*

>
  require("truss").setup({
    command = "truss-cli",
    arguments = {},
    attach_current_buffer = true,
    attach_diagnostics = true,
    attach_git_diff = true,
    maximum_context_characters = 100000,
    panel = { position = "right", width = 52 },
  })
<

The current buffer or visual selection is attached only when the user invokes
`:TrussChat`. Opening Neovim or the Truss panel never sends workspace content.
API keys stay in the CLI environment or user-level Truss configuration.

==============================================================================
COMMANDS                                                    *truss-commands*

`:TrussOpen`             Open or focus the Truss split.
`:TrussChat [prompt]`    Start or continue a streaming Chat run.
`:TrussPlan [prompt]`    Start a read-only Plan run.
`:TrussEdit [prompt]`    Start an Edit run with host-routed approvals.
`:'<,'>TrussChat`        Attach the selected lines to the prompt.
`:TrussStop`             Cancel the active request.
`:TrussNew`              Clear the panel and start a new session.
`:TrussStatus`           Show connection and run status.
`:TrussTestConnection`   Test the selected provider without starting a run.
`:TrussMcp`              Show credential-safe MCP server status.
`:TrussProfile`          Select a named CLI configuration profile.

Neovim's built-in `:checkhealth truss` command verifies the plugin, CLI,
workspace, and optional Git integration without starting the service.

Inside the Truss panel:

`<Enter>`                Prompt, or open the changed file under the cursor.
`gf`                     Open or focus the changed file under the cursor.
`<C-c>`                  Stop the active run.
`q`                      Close the panel without stopping the service.

Edit write requests prompt before execution. Write and replacement requests
offer a native diff preview. Profile selection, provider tests, MCP state,
approvals, and model traffic remain in the local service; Lua never stores
credentials.

==============================================================================
LAZYVIM                                                    *truss-lazyvim*

>
  require("truss.lazy").setup()
<

This optional helper maps <leader>tc/tp/te/to/ts and <leader>tP. It skips any
mapping that already exists and may be omitted or overridden.
